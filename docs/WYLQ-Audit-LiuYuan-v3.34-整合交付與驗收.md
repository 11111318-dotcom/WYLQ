# WYLQ-Audit｜六元正紀 v3.34.0 整合交付與驗收

## 功能定位與入口

本模組不是獨立查詢工具，也不要求使用者再選一次歲干支。使用者照常輸入出生資料並選擇「目標分析年份」後，主程式依既有目標快照產生 target.gz.gz；六元正紀面板直接以該值查表，與目標年份結果一起顯示。

面板位於結果頁「值年大運與司天在泉政令總覽」之後，直接標示「目標分析年份＋年干支」。生辰輸入頁不放置獨立查核按鈕，介面也不再出現第二個六十甲子選單或查詢對話框。

## 查核內容

- 《素問・六元正紀大論》經文合論正化度；依省文碼展開上、中、下三項。
- 《玄珠密語》等正化／對化分論生成數，附地支正對屬性、歲運數值依據及方位／月建解釋。
- 90 個上、中、下位置的數值對照標籤。
- 邪氣化度與災宮、藥食宜，以及可展開的原典原文。
- 自動以所選目標歲次干支載入，不再人工挑選另一個干支，避免主程式目標年份與典籍查核歲次不一致。

## 本次設計修正

- 移除獨立的六元正紀對話框、歲干支選單與手動查詢入口。
- 新增結果頁自動呈現面板，輸入來源固定為 computeLiuYuanZhengJiInfo(target.gz.gz)，與主程式同一份目標快照共用年干支。
- 將新面板加入成功計算時的渲染流程、結果清空清單及失敗回滾快照，避免重複計算殘留前一個年份的內容。
- 六元正紀呈現模組自身發生錯誤時，只顯示局部警告，不使主要運氣計算失敗。
- 「取自正化歲／對化歲」標籤保留為數值相符判讀；不單憑數字相等推定原典作者的實際取值推導。
- 土數依「土常以生」與「土無成數」例外處理。
- 所有動態查詢文字以 DOM textContent 建構；沒有新增外部相依或網路請求。
- 修改 inline script 後重算並更新 CSP script hash；index.html 與 docs/index.html 保持逐字節同步。
- CI 靜態回歸測試保證沒有第二個手動干支選單／對話框，並要求自動面板以 target.gz.gz 為輸入、隨每次主程式推算重新渲染。

## 理論與醫療邊界

「數值相符」是程式依內建資料表所作的數值比較，不證明《素問》作者實際採用哪一條生成推導，也不表示《素問》合論與後世正化／對化分論完全等同。藥食宜僅供古典運氣文獻對照，不是臨床處方；實際用藥與食療應由合格中醫師依四診合參決定。
