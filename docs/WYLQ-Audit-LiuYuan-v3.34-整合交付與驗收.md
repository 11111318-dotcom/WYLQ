# WYLQ-Audit｜六元正紀 v3.34.0 整合交付與驗收

## 版本與入口

以 WYLQ-Audit `3.33.3-security` 為底版，整合《素問・六元正紀大論》六十甲子查核面板。**入口位於結果／查詢頁的摘要卡下方、觀測查詢區上方；生辰輸入頁不再顯示此功能。**

使用者先進入主程式的查詢／結果頁，即可在「典籍查詢｜《素問・六元正紀大論》」卡片開啟查核對話框。查核模組本身僅依所選歲干支及內建典籍資料表運算，不讀取或改寫出生資料與個人推算結果。

## 查核內容

- 六十甲子歲干支選單。
- 《素問・六元正紀大論》經文合論正化度；省文按結構展開為上、中、下三項。
- 《玄珠密語》等正化／對化分論生成數，並列顯示地支屬性、歲運數值依據及方位／月建解釋。
- 90 個上、中、下位置的數值對照標籤。
- 邪氣化度、災宮、藥食宜及可展開的原典原文。

## 本次修正與安全界線

- 將查核入口從生辰輸入頁移至結果／查詢頁，不再將典籍查核混入出生資料輸入流程。
- 將「取自正化歲／對化歲」的強因果式標籤改為「數值相符」，避免僅憑數字相等推定原典的取值來源。
- 土數按「土常以生」及「土無成數」例外處理。
- 查詢輸出以 DOM `textContent` 建構，不將查詢資料插入 `innerHTML`；不增加外部相依性或網路請求。
- `index.html` 與 `docs/index.html` 保持逐字節同步；此處只調整介面標記及說明文字，inline script 未修改，原 CSP script hash 不變。
- CI 加入介面位置回歸測試，確保查核入口不會再次放回生辰輸入頁。

## 驗收

既有 v3.34 六元正紀模組測試與主程式安全／CSP、九宮／靈龜八法回歸測試保持啟用；新增 UI 位置測試確認入口位於結果／查詢頁摘要卡後方，且不在生辰輸入頁。

## 理論與醫療邊界

「數值相符」是程式依內建資料表作出的數值比較，不證明《素問》作者實際採用哪一條生成推導，也不表示《素問》合論與後世正化／對化分論完全等同。藥食宜僅供古典運氣文獻對照，不是臨床處方；實際用藥與食療應由合格中醫師依四診合參決定。
