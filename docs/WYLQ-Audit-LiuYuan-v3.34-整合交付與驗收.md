# WYLQ-Audit｜六元正紀 v3.34.0 整合交付與驗收

## 版本與範圍

本次以 GitHub 主分支既有的 `WYLQ-Audit 3.33.3-security` 單檔應用為底版，加入《素問・六元正紀大論》六十甲子查核面板。主程式原有的出生日期、流年、運氣推算與既有九宮／靈龜八法介面不改寫；新增模組只由獨立查詢面板呼叫。

## 使用方式

1. 開啟應用首頁，在出生資料表單下方找到「典籍查核工具｜《素問・六元正紀大論》」。
2. 點選「開啟六十甲子查核」，選擇任一歲干支，再按「查詢此歲」。
3. 面板分成兩條並列軌道：
   - **軌道一**：原典合論正化度，展開上／中／下三項，並保留省文及異名說明。
   - **軌道二**：依《玄珠密語》等正化／對化分論生成數，顯示地支屬性、歲運數值依據與方位／月建解釋。
4. 下方另列邪氣化度與災宮、藥食宜，以及可展開的原典原文與本組資料。

## 本次整合項目

- 新增 60 甲子選單；查詢不要求出生日期、出生時間或先跑主程式的個人推算。
- 對 30 組對沖歲紀的原典條目，依省文碼展開上／中／下三個位置。
- 對 90 個位置自動標註「兩歲同值」或「合論數值與正化／對化分論值相符」。
- 將「取自正化歲／對化歲」的強因果式標籤改為**數值相符**，並提示不能單憑相等證成原典推導來源。
- 保留「土常以生」及「土無成數」例外，不把土數五一概說成生數與成數皆五。
- 所有新增查詢輸出以 DOM `textContent` 建構，不將查詢資料插入 `innerHTML`；不增加外部相依性或網路請求。
- 更新 inline script CSP SHA-256；CSS 未修改，既有 style hash 保留。同步更新 `index.html` 和 `docs/index.html`，維持部署工作流程要求的逐字節一致。

## 理論與醫療邊界

「相符」是程式依既有資料表所作的數值比對，不證明《素問》作者實際採用哪一條生成推導，也不代表《素問》合論與後世正化／對化分論在理論上完全等同。藥食宜內容只作古典運氣文獻對照，不是臨床處方；實際用藥與食療應由合格中醫師依四診合參決定。
